# ☕ Cafe App

바닐라 HTML/CSS/JS로 만든 카페 주문 웹앱입니다. 빌드 도구나 프레임워크 없이 정적 파일만으로 동작하며, 데이터는 브라우저 `localStorage`에 저장됩니다.

## 주요 기능

**고객**
- 메인 페이지 / 메뉴 조회 (카테고리·검색·정렬)
- 장바구니 (수량 조절, 모의 결제)
- 주문 내역 조회 / 주문 상세
- 마이페이지 (장바구니·주문 현황 요약)

**관리자**
- 대시보드
- 메뉴 관리 (등록/수정/삭제, 품절 처리, 이미지 업로드)
- 주문 관리 (목록/상세, 상태 변경)

## 기술 스택

- HTML / CSS / JavaScript (Vanilla, 프레임워크 없음)
- `localStorage` 기반 데이터 저장 (별도 백엔드 없음)

## 폴더 구조

동일한 디렉토리에 `.html` / `.css` / `.js`를 나란히 두는 코로케이션 구조입니다. 전역 공용 리소스만 `css/`, `js/`에 분리되어 있습니다.

```
├── index.html / index.css / index.js   # 메인 페이지
├── menus/                              # 메뉴 조회
├── basket/                             # 장바구니
├── orders/                             # 주문 내역
├── my/                                 # 마이페이지
├── admin/                              # 관리자 (대시보드, 메뉴/주문 관리)
├── css/variables.css                   # 전역 CSS 변수
├── js/data.js                          # 메뉴 데이터 레이어
├── js/utils.js                         # 공용 유틸리티 (장바구니, 포맷 등)
└── images/, assets/                    # 이미지·영상 리소스
```

자세한 설계 내용과 구현 체크리스트는 [BLUEPRINT.md](BLUEPRINT.md)를 참고하세요.

## 실행 방법

빌드 과정이 없는 정적 사이트라 별도 서버 없이도 열리지만, 상대경로 리소스(이미지, 영상 등)가 정상 동작하려면 로컬 서버로 여는 것을 권장합니다.

- VS Code의 **Live Server** / **Five Server** 확장으로 프로젝트 루트를 열기
- 또는 `index.html`을 시작 페이지로 하는 임의의 정적 서버 사용

## 데이터 초기화

메뉴/장바구니/주문 데이터는 브라우저 `localStorage`에 저장됩니다. 브라우저 개발자 도구에서 `localStorage.clear()`를 실행하면 초기 시드 데이터로 리셋됩니다.
